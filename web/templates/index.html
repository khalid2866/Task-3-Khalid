Pipeline blueprint

  1. Prompt Payload Formulation — aspect ratio → exact pixel payload; engine char limits enforced.
  2. Network API Gateway — split timeout (3.05s, 60s); ConnectTimeout fails fast, ReadTimeout/429/503 retry with exponential backoff + jitter.
  3. Security & Moderation Gates — Gate 1 input filter (instant, 0 compute); Gate 2 output filter (blurred placeholder on block).
  4. Transport Protocol — memory-safe chunked streaming, 64 KiB slices straight to disk.
  5. Integrity Verification — forced Image.open().load() pixel decode; truncated assets discarded + retried.
  6. Automated QA — Lens 1 aesthetic score > 7.0/10 or discard; Lens 2 semantic alignment flags divergent assets.
